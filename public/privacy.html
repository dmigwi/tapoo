Privacy Notice

Tapoo Browser Privacy

In the current Tapoo game version highlighted at the bottom of this page, normal gameplay state stays on your device. Gameplay data is not sent to a remote service by Tapoo unless you configure AI Agent mode to request predictions from an agent API endpoint.

Browser Storage

Tapoo uses localStorage to keep durable game preferences such as level, wall weight, score-retention metrics, and optional AI Agent configuration. It uses sessionStorage for the active round snapshot so a refresh can restore the current maze session.

This data stays on the current device unless you clear it through browser settings or use Tapoo controls such as Reset Progress. Stored values are lightly obfuscated to reduce casual tampering, but this is not strong encryption for personal data.

AI Agent Mode

AI Agent mode can send gameplay context to agent API endpoints that you configure. That context may include the current cell, destination cell, player name, model name, allowed moves, submitted moves, score, level, and traversal history.

Only configure endpoints you trust. External endpoints may receive network metadata such as your IP address and may process gameplay context under their own policies.

Hosting

If you use the GitHub Pages deployment, GitHub may process routine hosting metadata such as request logs, IP address, browser details, and timestamps under GitHub's own terms and privacy practices.

Your Controls

You can reset game progress from the game controls and clear stored site data from your browser settings. If AI Agent configuration is added, remove endpoints you no longer trust before using that mode.

Project Status

This notice explains the current browser data flows. It is not a legal certification that Tapoo satisfies every GDPR obligation in every deployment context.
