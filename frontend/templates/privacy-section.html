Tapoo Privacy Policy

Introduction

Tapoo v{{softwareVersion}} is a browser-based AI agent behavior profiler tool. It works by having an agent guide a player through a maze to a target - a task built around structured uncertainty, where the target position is known but the success route through the maze is purposely ambiguous. Tapoo records what the agent does under that uncertainty. The maze is a real game you can play yourself in the Interactive mode, but the reason it exists is the AI Agent's output record it produces: the material a behavior profile is built from, one per agent reviewed. A profile is a record of what a single agent was observed to do - the capabilities it demonstrated and the violations it committed - both read from that agent's own output rather than inferred from anything else.

Tapoo supports two control modes: Interactive mode, where you play directly, and AI Agent mode, where every enabled agent seat plays on your behalf in turn, each asking the agent API endpoint you configured for that seat what to move next. Profiling is what AI Agent mode exists for; Interactive mode is the same maze without an agent in the seat. In both modes, session state stays on your device; Tapoo sends no data to a remote service unless you enable at least one agent seat.

Data Tapoo Stores

Tapoo uses localStorage to keep durable game preferences such as level, wall weight, score-retention metrics, optional AI Agent seat configuration, and the first-run acknowledgement of this Privacy Policy. Each configured agent seat holds the display name you gave it, the model name, the endpoint URL, which provider dialect that endpoint speaks, the reasoning-effort setting, how often the seat may issue a request, and whether Echo Back Reasoning is enabled for it, plus a creation timestamp used to tell one occupant of a seat from the next. Some providers also require a bearer token or API key, and some need extra request headers. Those values are stored alongside the rest of the agent's configuration under the same light obfuscation described below - they are recoverable by anyone with access to your browser profile, so only enter a credential or header value you would accept being read that way.

Tapoo uses sessionStorage for the active round snapshot, per-tab AI Agent session metrics, and the tab-session ID used to scope Tapoo Logs. Those session metrics are per seat and per tab: whether the seat is switched on, whether a network error switched it off and when, the level and round it last played, and the turns and score decay it has accumulated in that round. They are kept apart from the durable seat configuration above so that two tabs can play different games at once without one tab's play being counted against the other's.

Tapoo Logs are stored in IndexedDB when available. They are the profiler's primary output rather than a debugging side effect: every request sent to an agent endpoint and every response it returned, the encoded maze each level started from, the moves replayed and what they cost, and the timing and context around each turn. This is the material a behavior profile is built from, so they exist to be read back - downloaded and analysed after a run, or compared between runs and between agents. Logs stay on your device, are scoped to the current browser tab session, and can be downloaded or cleared from the game controls. If IndexedDB is unavailable, Tapoo falls back to sessionStorage for logs, and AI Agent mode is then capped at level {{fallbackAgentApiMaxLevel}}: starting a higher level shows a storage notice instead of playing it. The cap exists because browsers limit sessionStorage to roughly 5MB per site, which a single high level's logs can exceed on their own - past that limit the browser refuses further writes and the log stops recording the run it is meant to describe. Interactive mode is not affected by that cap, and no cap applies at all when IndexedDB is available. A second limit is unrelated to storage and applies in both modes: a level is only played if its maze fits the visible area, so a window too small for the level shows a screen-room notice until it is enlarged.

All of this remains on your device unless you clear it through browser settings or use Tapoo controls such as Reset Progress. Stored values are lightly obfuscated to reduce casual tampering, but this is not strong encryption for gameplay data. Every stored entry is also tagged with Tapoo's storage schema version, which is separate from the app version named above. Upgrading Tapoo to a new schema version does not migrate entries left over from an older one, and the upgraded page cannot read them. Instead, the next time you open Tapoo it tells you how many leftover entries exist and which version wrote them, and asks you to confirm before removing them. Nothing is deleted until you confirm, and confirming does clear previously stored preferences and AI Agent configuration, including any credential or header values saved with an agent.

Third-Party Sharing (AI Agent Mode)

AI Agent mode sends gameplay context to the agent API endpoints you configure. That context may include the current cell, destination cell, player names (user-chosen in-game nicknames), model name, allowed moves, submitted moves, score, level, and traversal history - each entry recording a visited cell and, for that cell, every open exit mapped to its neighbouring cell and whether that neighbour has already been visited. It also includes the raw counts behind a traversal-speed classification - unique cells visited and decay units charged this level (turns taken is included too, for context only) - and the classification itself: a rate (unique cells visited divided by decay units charged) below 1.0000 is Backtracker, exactly 1.0000 is Navigator, and above 1.0000 is Trailblazer. An agent starts out as a Trailblazer and is expected to maintain that rank throughout the game. The rank is shown in the agent seat roster in your browser and included in the prompt sent to the configured agent endpoint. If Echo Back Reasoning is enabled for an agent, its own previously returned reasoning content is also included in later requests within the same turn, sent back to that same endpoint.

Only configure endpoints you trust. External endpoints may receive network metadata such as your IP address and may process gameplay context under their own policies.

Hosting Provider

The service that hosts the Tapoo website may process routine request metadata such as request logs, IP address, browser details, and timestamps under its own terms and privacy practices.

Your Choices and Controls

You can reset game progress, download Tapoo Logs for the current tab session, or clear Tapoo Logs from the game controls. Clearing Tapoo Logs removes the current tab-session logs and stale same-mode log sessions that have not updated their activity timestamp for at least 60 minutes. When leftover data from an older storage schema version is present, Tapoo asks you to confirm its removal before the game loads; this is a notice rather than a choice to keep that data while playing, since the upgraded page cannot read it either way. Declining simply means not continuing, and the data stays on your device until you return and confirm - so if you want to keep a copy, export it through your browser's developer tools before confirming. To remove all stored site data, use your browser settings. If you have configured AI Agent endpoints, remove any you no longer trust before using that mode. Tapoo also reads your browser's Reduce Motion (prefers-reduced-motion) setting to decide whether the maze target marker blinks or stays steadily visible; this preference is read live from your browser on each check, never stored by Tapoo, and never sent anywhere.
